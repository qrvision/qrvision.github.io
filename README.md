# QR Vision — Free Online QR Code & Barcode Scanner

🌐 **Live Site:** [https://qrvision.github.io/](https://qrvision.github.io/)

**QR Vision** is a fast, privacy-first, client-side web application for scanning QR codes, reading 1D barcodes, and generating static QR codes directly in any modern browser — with zero app downloads and zero server uploads.

## Features

- **Online QR Code Scanner** ([qrvision.github.io](https://qrvision.github.io/)) — Scan via live camera (with flashlight toggle), image upload, drag-and-drop, or clipboard paste (`Ctrl+V`).
- **Online Barcode Scanner** ([qrvision.github.io/barcode.html](https://qrvision.github.io/barcode.html)) — Supports EAN-13, EAN-8, UPC-A, Code 128, and Code 39.
- **Free QR Code Generator** ([qrvision.github.io/generator.html](https://qrvision.github.io/generator.html)) — Create non-expiring static QR codes for URLs, Wi-Fi networks, plain text, emails, and phone numbers with PNG export.
- **Smart Action Detection** — Automatically detects URLs, Wi-Fi credentials, vCards, email links, phone numbers, SMS, and map coordinates.
- **100% Private & Offline PWA** — All decoding runs locally in your browser; recent scan history is stored only in `localStorage`.
- **Multilingual** — Available in English (`/`), Portuguese (`/pt/`), French (`/fr/`), Spanish (`/es/`), and Hindi (`/hi/`).
