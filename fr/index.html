Historique Récent (Stocké Localement)

    Comment Scanner un QR Code en Ligne

    1. Lancez la Caméra ou Importez un Fichier : Cliquez sur Démarrer la Caméra ou déposez vos images/PDF.
    2. Centrez le QR Code : Placez le code face à l'objectif avec un bon éclairage.
    3. Vérifiez et Agissez : Contrôlez le domaine détecté, ouvrez le lien ou exportez en CSV.

    Questions Fréquentes (FAQ)

    Comment scanner un QR code sans télécharger d'application ?

    Ouvrez QR Vision dans votre navigateur, cliquez sur Démarrer la Caméra et pointez vers le QR code.

    Puis-je lire un QR code depuis une image ou un PDF ?

    Oui. Importez des images ou fichiers PDF, ou collez directement une capture via Ctrl+V.

    Mes données scannées sont-elles envoyées sur un serveur ?

    Non. L'analyse se fait 100% localement dans votre navigateur ; aucune donnée n'est transmise.
